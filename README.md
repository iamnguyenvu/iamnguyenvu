## 🚀 About Me

I am a **Software Engineer and Technical Lead** focused on building reliable, scalable, and maintainable software systems across backend, full-stack web, mobile, and infrastructure.

My strongest work sits at the intersection of:

- 🧭 **System analysis & architecture design** — requirements breakdown, service boundaries, domain modeling, API contracts, database design, technical planning
- 🧩 **Distributed backend systems** — Java 21, Spring Boot, NestJS, PostgreSQL, Redis, Kafka, RabbitMQ
- ⚡ **Realtime communication** — WebSockets, Socket.IO, Redis Adapter, WebRTC signaling, presence, typing, push notification
- 🎬 **Streaming platforms** — HLS, FFmpeg, Vidstack, HLS.js, Nginx caching, Cloudflare deployment
- 🤖 **AI-enabled products** — Gemini, Ollama fallback, Spring AI, RAG, pgvector, Redis-backed chat history
- 📱 **Full-stack product delivery** — Next.js, React, Flutter, React Native, Expo, Tailwind CSS, Docker, AWS EC2

<details>
  <summary><b>💬 VNALO — Distributed Realtime Messaging System</b></summary>

<br/>

**Role:** Technical Lead & Backend Architect  
**Stack:** Java 21 · Spring Boot · NestJS · PostgreSQL · Redis · Kafka · RabbitMQ · Socket.IO · WebRTC · Flutter · React · Docker · AWS EC2

Production-oriented messaging and social platform supporting chat, media delivery, push notifications, QR login, WebRTC calling, AI smart replies, and web/mobile clients.

**Highlights**

- Architected a polyglot distributed platform with Java Spring Boot microservices and NestJS services.
- Implemented **CQRS Inbox Pattern** with a denormalized `conversation_inbox` projection.
- Used **atomic Redis sequence IDs** for ordered message delivery and concurrency-safe sequencing.
- Built realtime communication with Socket.IO, Redis-backed user rooms, presence, typing, and cross-node delivery.
- Integrated Kafka → Firebase FCM notification delivery and Gemini/Ollama AI smart replies.

**Why it matters:** distributed system design, service boundaries, realtime architecture, event-driven pipelines, AI integration, and production deployment.

</details>

<details>
  <summary><b>🎬 DONGHUA3D — HLS Movie Streaming Platform</b></summary>

<br/>

**Role:** Full-stack Developer & Deployer  
**Stack:** TypeScript · Express.js · Next.js · Prisma · PostgreSQL · Vidstack · HLS.js · FFmpeg · Nginx · Docker · Cloudflare

Full-stack streaming platform for 3D donghua movies with HLS playback, movie/episode management, dual-track rating, watch party sync, and production deployment.

**Highlights**

- Built a custom HLS streaming pipeline with Vidstack and HLS.js.
- Designed FFmpeg transcoding with **GOP-aligned segmentation** for accurate seeking.
- Added mutex-locked encoding flow to protect limited server resources.
- Implemented User/Expert dual-track rating and credibility gate.
- Deployed behind Cloudflare DNS/SSL and Nginx reverse proxy with caching and compression.

**Why it matters:** full-stack product engineering, media processing, streaming architecture, database modeling, and infrastructure setup.

</details>

<details>
  <summary><b>✈️ Airline Service Assistant — AI Flight RAG Assistant</b></summary>

<br/>

**Role:** Backend / AI Application Developer  
**Stack:** Java · Spring Boot · Spring AI · PostgreSQL · pgvector

AI-powered flight service assistant designed around retrieval-augmented generation for airline support workflows.

**Highlights**

- Built a Spring Boot backend for AI-assisted airline service interactions.
- Designed retrieval workflows using vector search and domain-specific context.
- Structured the assistant around practical service questions instead of generic chatbot behavior.
- Focused on reliable API boundaries and maintainable backend architecture.

**Why it matters:** applied AI engineering, retrieval design, vector search, and domain-specific assistant behavior.

</details>

<details>
  <summary><b>🍱 DearU Food — Mobile Food Delivery Application</b></summary>

<br/>

**Role:** Mobile / Full-stack Developer  
**Stack:** React Native · Expo · Supabase · Zustand · TanStack Query · AsyncStorage · Maps

Mobile food delivery app focused on cart management, location handling, map-based delivery UX, and server-state caching.

**Highlights**

- Built atomic client-side state management with Zustand.
- Used AsyncStorage persistence for offline-friendly cart behavior.
- Integrated TanStack Query for predictable server-state caching.
- Implemented map/location features with Expo Location and React Native Maps.
- Designed deterministic cart item keys for reliable cart updates.

**Why it matters:** mobile product development, offline resilience, server-state caching, and location-based UX.

</details>
